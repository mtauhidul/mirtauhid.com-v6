# mirtauhid.com (v6)

Personal portfolio. Next.js · TypeScript · Tailwind CSS.

## Getting started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

## Scripts

| Script        | Purpose                         |
| ------------- | ------------------------------- |
| `pnpm dev`    | Start dev server                |
| `pnpm build`  | Production build                |
| `pnpm check`  | Lint + typecheck + format check |
| `pnpm format` | Format with Prettier            |
